How It Works

One Session, Five Routes

There are 7 sessions in total. For each one, choose your preferred route based on your workflow and needs.

1. Set Up Your Tools

Five minutes, once. Chat and the 3D Browser need nothing installed; Python and R are one install each (or Colab); MCP is one URL in your AI client. Setup guide →

2. Pick Your Route

Python or R for reproducible analysis · Chat for quick answers · MCP for LLM-powered exploration · 3D Browser for visualization

3. Work Through the Sessions

Start with Session 1: Discovery and progress through seven sessions that build on each other, from finding neurons to integrating transcriptomics.

4. Apply to Your Research

Use the same workflows with your own neurons, regions, and genes. All examples include VFB IDs for reproducibility.

What's New for 2026

Expanded Connectome Coverage

The fly CNS is now covered by whole-CNS and sex-specific connectomes that didn't exist (or weren't integrated) at the last workshop:

  • BANC (Brain And Nerve Cord) — whole adult CNS
  • male-CNS — adult male CNS
  • MANC — male adult nerve cord
  • Optic Lobe (JRC_Optic-Lobe v1.0.1)

Plus the VFB MCP tool and chat.virtualflybrain.org interface for natural-language exploration.
